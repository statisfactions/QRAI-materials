# CORE103: Quantitative Reasoning in the AI Age

Student notebooks for CORE103 at Fulbright University Vietnam, Fall 2026. Instructor: Ethan C. Brown, Ph.D.

Students open these in Google Colab from links on Canvas, then save their own copy with **File > Save a copy in Drive**. In the tables below, a notebook's name opens it for reading on GitHub, and the Colab link opens it ready to run. Any notebook here opens in Colab with a link of this form:

`https://colab.research.google.com/github/statisfactions/QRAI-materials/blob/stable/<folder>/<file>.ipynb`

The `stable` branch is what students see. `main` holds revisions that are waiting for a later class or the next offering.

## What is here, and what is not

This repository holds only the **Colab notebooks** and the data they load. A good part of the course happens elsewhere:

- **Worksheets written as Google Docs:** 1.2, 3.2, 8.2 and 10.1. These are on Canvas.
- **NetLogo models** for the Quant unit. Most come from the NetLogo Models Library; the climate model is in `Climate/`.
- **In-class activities, slides, project briefs and the syllabus** are on Canvas and OneDrive.
- **Solutions and test items** are kept private and are never published here.

## Caveats

- **This is a course in progress.** Worksheets are revised during the term, usually just before the class that uses them, so a notebook for a class that has not happened yet may still change.
- **The ML notebooks are the Spring 2026 versions.** They have the Fall class numbers but have not had their Fall revision yet. Expect the Fall versions to be similar in content.
- **The AI Mini-Unit is being revised for Spring 2027.** It will put more weight on quantitative reasoning, and the Mini-Project may change.
- **File names are not fully consistent.** Some carry a `_ws` suffix or underscores from earlier versions. Renaming them would break the links students already have.
